# Repository guidelines for Claude Code

## Git

- **Never commit without explicit review and approval first.** Make the changes,
  summarize what changed, and wait for the user to review and say to commit.
  Do not run `git commit` proactively — even after completing work the user
  asked for, or when reformatting/lint hooks would otherwise run cleanly.
- The same applies to `git push` and opening PRs: confirm with the user first.
